# Brew Haven API ☕

A REST API developed using Node.js and Express.js as part of the Brew Haven Internship Project.

## Technologies Used

* Node.js
* Express.js
* Postman

## Features

* Create Coffee
* Get All Coffees
* Get Coffee by ID
* Update Coffee
* Delete Coffee
* REST API Development
* Postman API Testing

## API Endpoints

### Get All Coffees

GET /coffee

### Get Single Coffee

GET /coffee/:id

### Add New Coffee

POST /coffee

### Update Coffee

PUT /coffee/:id

### Delete Coffee

DELETE /coffee/:id

## Installation

Install dependencies:

npm install

## Run the Project

Start the server:

node server.js

Server runs on:

http://localhost:8000

## Testing

The API was tested using Postman by performing:

* GET Requests
* POST Requests
* PUT Requests
* DELETE Requests

## Project Outcome

Successfully built a RESTful API using Node.js and Express.js implementing complete CRUD operations for coffee management.
